# Contributing to Mergington High Activities Website

Thanks for helping improve the extracurricular activities website! This document explains how teachers and staff can contribute.

## How to contribute

1. **Find or open an issue** describing the change you want to make.
2. **Create a branch** from `main` with a descriptive name (e.g., `add-chess-club`).
3. **Make your changes** and commit them with clear commit messages.
4. **Open a pull request** targeting `main` and fill in the description.
5. **Request a review** from a maintainer and wait for approval before merging.

## Guidelines

- Keep pull requests small and focused on a single change.
- Follow the existing code style in `src/`.
- Be kind and constructive in reviews — we are all volunteers!
- Report security vulnerabilities privately via `SECURITY.md`, not in public issues.

## Need help?

Open a discussion or an issue and a maintainer will get back to you.
